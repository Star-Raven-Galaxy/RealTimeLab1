# Лабораторная работа №1

Консольное приложение на Python 3.10+ для классификации задач и вычислительной системы реального времени по жёсткости временных ограничений и по типу дедлайна, а также для расчёта временных характеристик набора задач.

## Возможности

- Классификация задач по жёсткости: жёсткое, твёрдое, мягкое.
- Определение класса системы в целом (жёсткого или мягкого РВ).
- Определение типа дедлайна: неявный (D = T), ограниченный (D < T), произвольный (D > T).
- Расчёт запаса `L = D − C` и признака выполнимости дедлайна (`L ≥ 0`).
- Поиск критической задачи — жёсткой с минимальным запасом.
- Расчёт требуемого времени реакции `R_треб = min(D)` по жёстким задачам.
- Расчёт коэффициента загрузки `U = Σ (C_i / T_i)` и проверка `U ≤ 1`.
- Определение архитектурного класса: однопроцессорная, многопроцессорная, распределённая.
- Чтение исходных данных из `.json` или `.csv` (формат определяется по расширению).
- Вывод таблицы по задачам и текстового заключения в консоль.

## Требования

- Python 3.10 или выше.
- Сторонних библиотек нет, только стандартная библиотека.


## Запуск

Из корня проекта:


python src/main.py data/tasks.json
